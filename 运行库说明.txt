  运行库说明（西门子软件 + 本工具）
════════════════════════════════════════════════════════

【本工具需要什么运行库？】
  不需要！SiemensInstallHelper.exe 是自包含的，
  Python 环境和图形界面都已打进 exe，拷到任何
  Windows 10/11 电脑直接双击就能跑，不用装任何东西。

【已经下载好的运行库（本文件夹『运行库』目录）】
  vc_redist.x64.exe   —— VC++ 2015-2022 x64（24 MB）
  vc_redist.x86.exe   —— VC++ 2015-2022 x86（13 MB）
  安装方法：双击 SiemensInstallHelper.exe → 点『⑦ 安装运行库』
            （自动静默安装，会弹 UAC），或手动双击这些 exe。

【西门子软件可能还需要什么运行库？】
  下面这些是 TIA Portal / STEP 7 安装时常见的依赖。
  缺哪个装哪个，全部来自微软官方下载页。

1) Microsoft Visual C++ 运行库（2015-2022，x64 和 x86 都要）
   官方下载（微软官方短链）：
     x64:  https://aka.ms/vs/17/release/vc_redist.x64.exe
     x86:  https://aka.ms/vs/17/release/vc_redist.x86.exe
   下载后双击安装即可，装完重启一次更保险。
   （本工具已自动下载好，见上面『运行库』目录）

2) .NET Framework 4.8
   官方下载页: https://dotnet.microsoft.com/download/dotnet-framework/net48
   （页面里找 "Runtime" 离线安装包，约 120MB）
   （本工具的『⑥ 下载运行库』会帮你打开这个页面）

3) .NET Framework 3.5（部分西门子组件需要）
   不用下载，用系统自带功能开启：
   控制面板 → 程序 → 启用或关闭 Windows 功能
   → 勾选 ".NET Framework 3.5（包括 2.0 和 3.0）" → 确定
   （需要联网，装完会提示重启）

【怎么用这份说明？】
  - 如果给别人装机：把下面的运行库安装包下载好后，
    直接放进本文件夹（和 exe 放一起），需要时双击安装。
  - 想快速知道自己缺什么：双击 SiemensInstallHelper.exe，
    点"④ 运行库检查"，会列出本机已装/缺失情况。
